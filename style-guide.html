Design System

The single source of truth for colors, typography, spacing and components across the landing page and the web application. Every value below is a CSS custom property declared in assets/css/design-system.css.

Brand ramp

One ramp, three steps, separated by contrast rather than by hue. Only the two darker steps are legible as text on white: --primary is a background color that carries white text on top of it.

  • --primary

    Brand orange · 3.0:1 · background only, never text

  • --primary-mid

    First legible step · 5.4:1 · AA for body text

  • --primary-dark

    Headings, hovers, accents · 12.4:1

  • --primary-soft

    Tinted background for ghost buttons and highlights

Surfaces and text

A muted surface is always painted with an opaque color, never with a translucent veil, so that nothing behind it bleeds through.

  • --background / --surface

    Page background and raised cards

  • --surface-muted

    Second plane: alternating sections, quiet panels

  • --foreground

    General dark, replaces pure black across the UI

  • --chrome

    Dark chrome: footer and application shell

Lines

Four roles ordered by hierarchy, not by tone. A divider inside a surface does not weigh the same as the border of a card, and a clickable card asks for more presence than a static one.

  • --line Divider inside a surface: list rows, separators
  • --border Default border of a surface
  • --control Border of an interactive element at rest
  • --control-hover The same element under the cursor

Status

Four roles, three pieces each: the solid one for dots and bars, the strong one for hover and for text on top of the soft one, and the soft one for chip backgrounds. The soft plus strong pairing passes AA by design. Success keeps a green of its own and warning moves to amber, so that neither collides with the orange brand.

  • danger Broken bottles, failed delivery, critical incident Critical
  • warning Delayed route, temperature out of range, pending review Delayed
  • success Delivered, incident resolved, sensor within range Delivered
  • info In transit, informational notice In transit

Alpha scales

Five steps for text and four for fills. Any value outside these nine is drift.

  • Aa --ink-80Emphasis
  • Aa --ink-70Supporting body copy
  • Aa --ink-60Descriptions, helper text
  • Aa --ink-50Metadata: dates, counters
  • Aa --ink-40Placeholders, dimmed icons
  • --fill-5Hover veil
  • --fill-10Chip, progress bar
  • --fill-20Strong fill, bar track
  • --fill-40Solid dot or marker

Typography

Manrope for the whole interface, with a system sans fallback. Headings use --primary-dark; body copy uses --foreground.

  • --text-5xl / 700Track every bottle
  • --text-4xl / 700Page heading
  • --text-3xl / 700Section heading
  • --text-xl / 700Card title
  • --text-lg / 400Lead paragraph for section introductions
  • --text-base / 400Body copy, the default reading size
  • --text-sm / 400Secondary copy, labels and buttons
  • --text-xs / 400Metadata, captions and chips

Spacing

A four pixel base step. Layout gaps use the scale directly, never arbitrary values.

  • --space-1 · 4px
  • --space-2 · 8px
  • --space-4 · 16px
  • --space-6 · 24px
  • --space-8 · 32px
  • --space-12 · 48px
  • --space-16 · 64px
  • --space-20 · 80px
  • --space-24 · 96px

Radius and elevation

Elevation is reserved for elements that genuinely float: hovered cards and overlays. A static card is defined by its border, not by a shadow.

Components

The building blocks shared by the landing page and the web application. A disabled control sits at low contrast on purpose, so that it reads as inert.

Static card

Defined by its border. Used for content that is read, not clicked.

Interactive card

Stronger border at rest and elevation on hover, because it can be clicked.
